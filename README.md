# Raimore Construction website

Static site: plain HTML, CSS and JavaScript with no build step.

- `index.html` and the other `*.html` files are the pages.
- `css/style.css` holds the shared styles. Colours and fonts are CSS variables at the top of the file.
- `js/main.js` handles the header, navigation, search, FAQ accordion and counters.
- `images/` holds logos, photos and partner marks. `files/` holds downloadable documents.
- `vercel.json` configures clean URLs and caching on Vercel. `.htaccess` does the same on Apache hosts.
